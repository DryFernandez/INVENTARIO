## 🎓 Para el Desarrollador

### Cómo Extender el Sistema

1. **Nuevo módulo**: Copia la estructura de Productos
2. **Nuevo componente**: Usa los componentes base de `common/`
3. **Nuevos estilos**: Usa las variables CSS definidas
4. **Nueva ruta**: Agrégala en `router.jsx` como ProtectedRoute

### Convenciones de Código

- Componentes en PascalCase
- Archivos CSS con mismo nombre que componente
- Variables CSS con prefijo `--`
- Funciones handler con prefijo `handle`
- Estados descriptivos (formData, isLoading, etc.)
